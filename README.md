# havenTrust

A unified banking dashboard that aggregates multiple bank accounts in one place — view balances, track transactions, and manage transfers without switching between apps.

🔗 Live Deployment: https://haven-trust-banking-app-7kej.vercel.app/

## Features

- Link and view multiple bank accounts from a single dashboard
- Simulated transfers with consistent, accurate balance updates
- Transaction history across all connected accounts
- Responsive UI, built to work well on both desktop and mobile

## Tech Stack

- **Frontend:** React, Next.js, Tailwind CSS
- **Backend:** Node.js, Express
- **Language:** TypeScript
- **Backend Services:** Appwrite
- **Bank Data:** Mono API (sandbox)

## Note

This project uses Mono's sandbox environment to simulate bank account linking, since production access requires a paid tier. All transactions and balances shown are simulated.
